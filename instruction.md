📢 EE4207 – Web Application Development

Project Topic Submission

Since there will be no written exam paper for this module, the main evaluation will be based on a Web Application Project + Viva/Project Evaluation.

According to the module content, the project should be related to developing a modern web application using technologies such as HTML, CSS, JavaScript, RESTful APIs, and full-stack frameworks like the MERN Stack / ASP.NET Core / Spring Boot.

You can select a practical web application idea such as:

Example:
Academic Tracker System – students can register, log in, enter GPA/academic details, and track their progress.

Hosting the project is better, but even if it is not hosted, it should still be properly developed and demonstrated.

So please think of a suitable web application project topic and submit it as required.

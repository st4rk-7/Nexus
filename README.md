## Project Overview

**Nexus** is an IoT device registration, connectivity monitoring, and firmware rollout platform. Administrators upload firmware versions and monitor device status via a web dashboard, while connected devices communicate with the backend to query and download over-the-air (OTA) updates.

The goal for this module is applying DevOps practices from the ground up: containerization, automated infrastructure provisioning, configuration management, CI/CD pipelines, and application monitoring.
